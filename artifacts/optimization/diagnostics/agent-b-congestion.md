## 3. GND 扇出过孔候选代价模型的缺口分析

代码：`cloud_pcb/general_solver/run_blind.py::_add_gnd_fanout_vias`（~931–1277 行）与 `routing_guards.py`。候选生成：pad 外向 ±45°/±90° 五至八方向、按焊盘尺度缩放的距离序列；代价 `dist + 40 × area(焊盘尖 via+stub 几何 ∩ 走廊)`；走廊 = 差分对 pad 连线 buffer 0.6 + 密集 IC（≥6 铜焊盘）非 GND 脚径向 2.5mm buffer **0.20** 的并集（~1830–1880 行）。

| # | 缺口 | 证据 |
|---|---|---|
| G1 | **类别盲的固定间距阈值**：候选硬校验用 0.165（细间距 0.28）/stub 0.16/NPTH 0.22 常数，而路由器实际执行 DSN 类别间距（DIFF 0.198、POWER 0.198/线宽 0.5）。0.165 阈值放在 DIFF 脚旁会产出先天 DRC 冲突的 via；反之对 DEFAULT 又过保守 | case5 W 列：DIFF 经孔需求 0.473 vs 候选校验 0.165，差 0.31mm；§2.3.1 ④ |

## 4. 分层策略与拥塞的关系

- `run_blind` 层分配：DIFF_PAIR 类 → `(F.Cu, B.Cu)`；其余 → `F/In2/B`；In1 为地参考平面不参与布线（1877 行附近）。DSN 中每个 DIFF 类都有显式 `(use_layer F.Cu B.Cu)`。
- **该策略是 case5 M 对不可布的必要条件之一**：若允许 DIFF 逃逸段经 In2（经孔入内层），W 列笼死即可解除（v3 复检显示 In2 在输入与终态均连通）。差分保外层的 impedance 动机与盲规范的电气要求之间的关系在本轮数据中不可判定（spec 中无对应 gate），是提案 D 的核心权衡点。
- In2 拥塞可控：via guard 覆盖 In2，case5 In2 keepout 105 个；终态 In2 被实际使用（CKXTAL2/U2-CS 均经 In2），未观察到 In2 侧堵塞。
- 过孔总量：case4 317 个（大板、131 缝合孔）；case3 138；case5 113。开路与过孔总量的相关性弱于与**局部逃逸通道预算**的相关性。
- 平面掩蔽效应：case4 GND 未布通 1 条但 opens=1（S1-S1 被 In1 平面桶壁连通掩蔽）；说明 unrouted（DRC 侧）与 opens（LVS 侧）必须分开对待，前者是后者的子集信号。

## 5. 通用改进提案（无任何位号/网络名/案例条件）

> 纪律：全部以"盲规范的拓扑/焊盘几何/类别规则"为输入；位号与网络名仅用于本诊断定位。以下每条给出统一变体开关、预期指标与独立测试方案；不得以单案筛选替代完整轮次。

**P1 类别感知的间距与 keepout（修 G1）**
在扇出候选校验与 DSN keepout 生成中，把固定 0.165/0.28 阈值替换为按邻近焊盘所属类别的规则间距（via r + 该类 clr，对邻域取 max）；stub 同理。
- 依据：§2.3.1 ④（0.473 vs 0.165）；case5 实测 via-信号焊盘间距审计（<0.28mm 仅 2 处，当前未成灾，属预防性）。
- 预期指标：DIFF/POWER 引脚相关 opens↓；spacing=0 保持；ground_fill 不降。
- 适用条件：全案通用；对纯 DEFAULT 板无行为变化（阈值相同）。
- 测试：单元测试（给定类别规则的最近合法 via 距离函数）+ 完整轮次 `--hypothesis "class-aware fanout clearance"`，变体开关 `fanout_clearance_mode=class_aware`。

**P2 类别正确宽度 + 切向走廊的逃逸通道预算（修 G2/G3/G4）**
走廊 buffer 改为 w/2+clr（按类别），增加两类走廊：切向（沿 IC 边、穿焊盘轴向出端方向）与"焊盘尖外 via 带"（radial 0.275+clr 环带）；通道代价改为 guard 八边形并集与走廊的相交面积；随 via 放置增量更新各走廊剩余通行能力，当某方向走廊剩余容量低于该方向焊盘类别需求时，该方向候选代价置 ∞ 或自动转 unvia。
- 依据：§2.3.2（S 列 stub/guard 挤占唯一南向走廊）、§2.3.3（N 列南穿是实测成功模式而模型只保径向）、G3 面积低估 2.3×。
- 预期指标：unrouted↓（尤其 case5 类 0.4mm 间距 IC 的 DIFF/信号逃逸）、opens↓；监控 wirelength/vias 上升幅度、ground_fill 不恶化。
- 适用条件：密集封装（≥6 焊盘）周边；稀疏板行为不变。
- 测试：几何单元测试（走廊容量函数）；完整轮次 `--hypothesis "escape budget with class-correct corridors"`。

**P3 差分层策略变体评估（修 §4 绑定约束）**
以统一变体（如 `diff_routing_layers=allow_inner_escape`：仅允许差分**逃逸段**经 In2，平行耦合段仍限外层）做一轮独立实验。**前置**：核对盲规范差分电气要求是否绑定外层参考；若不可判定，实验结论只能作为"可行性上界"记录，不得直接晋基线。
- 依据：§2.3.1 W 列笼死的必要条件即 F/B 限制；In2 在输入/终态均连通。
- 预期指标：DIFF opens（case5 类 4 条）→ 0 的可行性验证；spacing=0；阻抗类 gate 现状为未知项，须保留 raw 违规记录不得改判。
- 测试：独立 freeze/unseal 完整轮次；与本轮基线逐板对比 opens/unrouted。

**P4 路由收敛热点反馈（修 G5，覆盖 case3/case4/case5-LED2/CKXTAL1 类）**
fastroute 收敛后若 unrouted>0，对每条未布通计算两端点"逃逸度"（本文 §2 的环向阻塞/via 落点/连通性三指标，纯几何、与网络名无关）：逃逸度显示可行（连通且落点充足）者判为搜索失败类，触发一次统一重试变体——改变 DSN 网络排序/类顺序（确定性种子），不改任何几何与规则。重试仍失败则如实保留。
- 依据：§2.1/§2.2/§2.3.3 三组"空间可走、收敛失败"；case4 S1-S1 在零障碍走廊上因次序翻转失败。
- 预期指标：unrouted↓ opens↓；代价仅求解时间。
- 适用条件：不与 P1/P2 冲突；重试次数固定（如 1 次）防刷结果；禁止重复同配置挑选幸运解。
- 测试：完整轮次 A/B（重试开/关）+ 单元测试（逃逸度指标对合成几何的判定）。

**P5 观察项（不计入改进承诺）**
(a) 同名引脚展开拓扑（J1 4×S1）在 bridge/router 链路的处理值得单独诊断，可能是 case4 GND 覆盖连接脆弱性的根源；(b) fastroute 输出存在 w=0.125<类宽 0.16 的线段而审计未拦截，宽度规则核查建议转交验证侧（Agent D 范畴）。

## 6. 不确定性与诚实记录

1. **分析脚本曾出现 pad 朝向错误并已修正**：初版按 spec (w,h) 直接旋转导致 N/S 列焊盘呈横条（同排互相重叠 0.53mm，物理不可能）。最终以 board.dsn pin padstack（`Rect_T_200x927` 等）为准。凡引用 N/S 列"输入空间 SPLIT/FULLY_SWALLOWED"的中间结论均已作废，报告中数值以 §2.3 手算（经 DSN 尺寸复核）与 routed 输出实测为准；W/E 列几何未受影响。
2. W 列 DIFF 笼死结论基于 shapely 膨胀近似 + 手工剖面核算（裕度 −0.043/−0.173/−0.074mm 三路封闭）；未用 fastroute 单网重放验证（受"不跑路由器全板求解"约束）。±0.01mm 级数值对净距定义（边-边 vs 中心线）敏感，但三路同时封闭的结论裕度充足。
3. case4 S1-S1 回归的精确归因（八边形 guard 改变搜索轨迹 vs 同名引脚拓扑歧义）需要受控重跑才能定论，本轮无法区分。
4. via-信号焊盘间距审计用 bbox 近似（把焊盘按 max(w,h)/2 当圆），实际边距会更大；两处 <0.28 的读数（0.175/0.271）是上界警报而非实测违例。
5. fastroute 为外部二进制，其内部通道/打孔离散化不可见；"搜索失败类"的判定依据是自由空间连通性（输入+终态）与同构引脚的成功对照，属强间接证据而非直接轨迹证据。
6. 遵守约束：未运行任何优化轮次/路由器求解；RUN 内所有文件未改动；本报告为新增诊断文档。
