# Conservative polygon pad export probe

FastRoute 0.1.14 and Freerouting 2.5.0 JVM accept convex polygon padstacks. In a synthetic four-layer plated-pad fixture with an explicit 0.130 mm rule, each engine went from four rectangular-envelope spacing findings to zero with polygon copper. The unchanged physical pad gap was 0.148098 mm. Both engines also retained four findings for the negative control whose true gap was 0.116985 mm.

No tracked source, input, rule or frozen result was changed. The draft is *intentionally unapplied*. `git apply --check .run/dsn-pad-geometry-probe/accurate-pad-geometry.draft.patch` succeeds against the source used to build it. The scratch `draft/overlay.py` loads the proposed bridge without modifying the repository's import tree. Six additional geometry tests and the seven existing secondary DSN tests passed through this overlay. The bridge option is `accurate_pad_geometry=True` and defaults to `False`.

FastRoute measured 0.0736 mm for the rectangular surrogate and 0.1132 mm for the real negative control. The differing signal routing was limited to the same one-pass synthetic budget. ## Geometry and integration

A rounded rectangle is the Minkowski sum of a core rectangle and a disk whose radius is the corner radius. An oval uses the same definition with a line core and a disk radius of half the smaller diameter. A square-corner rectangle at a non-cardinal angle uses a zero-radius disk. KiCad pad orientation is board-absolute, while the pad's local center offset rotates by the footprint angle; both are baked into DSN y-up positions with every package still placed `front 0`. Concrete copper layers, including a bottom-only pad or all four through layers, are retained exactly.

First circumscribe the disk inflated by 2 µm with 32 vertices at radius `(r + 2 µm) / cos(π/32)`. The convex hull of that polygon translated to the rotated core corners contains the intended copper plus a full 2 µm disk. Nearest-micron vertex rounding moves each vertex by at most `sqrt(2)/2 µm`. Any directional support of the hull can therefore shrink by at most that amount. Quantizing the real global pin center once adds at most the same error in the unfavorable direction. The combined loss is at most `sqrt(2) µm`, less than the bias. The DSN footprint+pin sum reconstructs the quantized world center rather than rounding its two frame transforms twice. Tests independently verify support half-planes, emitted polygon containment, bounded overhang and placement of the rounded, oval and off-axis rectangular cases. The shape key hashes ordered vertices and exact copper layers, with no decimal-dot suffix that either router could strip.

FastRoute `fr-dsn/src/model.rs:read_shape` and `fr-io/src/shapes.rs:padstack_shape`, plus Freerouting `io/specctra/parser/Shape.java:readPolygonScope` and `Library.java:readPadstackScope`, parse polygon vertices and build the convex hull. Neither router's default 45° search/DRC tree retains those facets: FastRoute `board/search_tree.rs:calculate_drill_tree_shapes` and JVM `board/searchtree/ShapeSearchTree.java:calculateTreeShapes(DrillItem)` use `bounding_octagon`/`boundingOctagon`. The resulting envelope conservatively contains actual copper but can still produce raw spacing failures and blocked escapes where arbitrary long pads turn off-axis, like the 30° fixture. Preserve those findings; do not filter by pad shape or observed physical distance. Retain default 45° routing. The unrestricted diagnostic experiment changes allowed bends and serves only to locate the approximation in the engine, not to propose a production rule change.

After the active freeze, wire this flag to both `board_to_dsn` calls of an optional variant and keep all shape-independent logic and hard gates. Cardinal rectangular pads, circles, headers, rule blocks, pin reference languages, NPTH handling and SES merge are unaffected. The patch explicitly rejects known chamfer features in the supported shapes rather than invent milled-pad copper. It does not claim support for custom/nonconvex copper or absent geometry fields. In a separate run, measure raw rules and source/applied placement individually, incl. decision evidence from all five known cases and authorized newly frozen validation inputs. Compare both primary and secondary raw reports to independent copper geometry. Historical failures caused by missing actual plated pad ownership, an unrelated geometry category identified in a separate probe, still remain recorded.
