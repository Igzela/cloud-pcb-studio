## What the pinned engine actually does

- `fr-io/src/network.rs:read_net`: nonempty `fromtos` **replace** the pad list with subnet pin lists. Do not use this option to keep ownership for omitted terminals. The legacy `skip_nets` and `override_net_pins` behavior removes physical pad ownership, which explains spurious pin-pin clearance records even when overlapping pads share a real net.
- `fr-engine/src/pipeline/stats.rs:ignored_incomplete_count` and `fastroute/src/report.rs`: `ignore_net_classes` changes what the search attempts and optimizer counts as work. The raw JSON `stats.unrouted` still includes those airlines and `unrouted_ignored_classes` is a subset. Neither a class skip nor reporting a subtraction creates connectivity.
- `fr-dsn/src/model.rs:read_fixed`, `fr-io/src/wiring.rs`, and `fr-io/src/ses_writer.rs:write_net`: `(type fix)` is SystemFixed. Export existing segments as `(wire (path F.Cu WIDTH XA YA XB YB) (net RETURN) (type fix))` and vias as `(via PADSTACK X Y (net RETURN) (type fix))`. SystemFixed wire/via is loaded and protects copper but intentionally absent from SES. Keep the original fixed copper when merging. Preserve the exact padstack diameter, drill size and copper layer span. Do not serialize a synthetic fixed copper path that is absent from the KiCad input.
- `fr-io/src/structure.rs:insert_plane`: `(plane RETURN (polygon In1.Cu 0 ...) (window (polygon In1.Cu 0 ...)))` is a physical conduction area, not an instruction to fill arbitrary missing copper. Host CAD is KiCad, so the window parser is enabled. Do not use layer `(use_net RETURN)` as a proxy for shape; implicit power-plane filling extends over the router board bounding box.
- `fr-engine/src/board/connectivity.rs`: via/through-pin center inclusion in the plane connects that item to the area if net and layer match. Trace contact uses exact centers or segment endpoints. Two conduction areas on a layer do not inherently join through shared polygon edges. `fr-engine/src/pipeline/autorouter.rs` can skip a terminal already on *any* plane piece even if a different piece holds another terminal. If an unsplit, connected polygon cannot represent the advertized reservation, use the backoff, not split-piece fiction.
- `fr-engine/src/board/item.rs:is_drillable` and `is_obstacle`: a default `(plane ...)` is not a foreign-via blocker. Foreign drills can sever or change an inner plane. An early area is not guaranteed by its DSN declaration. `fastroute/src/main.rs` also enables virtual stitching contacts for fixed vias with no actual connection. Require that every exported fixed via is already a real contact in the pre-route exact graph and verify the loaded log has no unexpected stitching/virtual-contact behavior. Avoid synthetic geometry added just to force the statistics.

## Proof obligation for a future experimental integration

Implement this as one general optional primary DSN mode, separate from the secondary lexer repair and independent of large-board placement experiments. Reuse a pure extracted helper for the exact pre-route In1 copper envelope and final pour constraints, rather than copy the hole/RF/edge arithmetic. Prefer one reserved reference layer (In1.Cu), with all foreign traces prohibited there by the existing rules. Via cross-layer drilling remains explicitly in the proof obligation. Stubs/vias are a second physical input alongside footprints, never substituted with netless keepouts as the sole representation of those same items.

1. Compute `pre_plane` from the physical board edge inset less the RF areas, NPTH drill clearance, all foreign through-pin/via antipads and existing foreign In1 traces. Use the same physical definitions as the existing pour generator. If a drill, fixed pad or outline has unsupported geometry that makes the physical model uncertain, omit this optimization for that board under the uniform geometry criterion. The physical ground ownership and all original pad net associations remain declared in either mode.
2. Select a single connected reservation `S` within `pre_plane` that contains each claimed preconnected plated anchor center and a small copper safety region around it. Only advertise anchors connected to actual intended pads through same-net copper and physical layer plating. A same-net SMD that lacks a fixed exit remains a routable terminal. Multiple disconnected `pre_plane` components are not equivalent nodes. If physically prelinked by an independent fixed copper graph, that fact can be modeled eventually, but the first candidate should fall back on any need to claim a second isolated plane component. Keep explicit polygon windows for holes inside the one chosen component. Do not decompose the one plane into multiple DSN wires touching only at boundaries.
3. Serialize conservative micron-grid geometry. For example, erode the proposed area by at least 2 micrometres, then round the exterior and all hole rings to 1 µm. Validate the resulting polygon is valid, positively oriented after the Y flip as required by loading, and is covered by `pre_plane` with no positive difference and no tolerance that could admit an unsafe new patch. Ensure ring quantization did not open a neck, omit a window, or move any claimed anchor outside the advertised area. Verify actual through-barrel and geometrically intersecting copper, not just 2D projection or a name match. Preserve preexisting manufacturing clearances; validate minimum neck widths independently before a fabricated board is claimed.
4. Run and retain the raw candidate SES/report, with no class/airline subtraction. Check that fixed export appeared in loader counts and intended real contacts match. The representation needs an explicit positive thermal-via compatibility test before enabling that subtype. Do not turn on unrestricted via-at-SMD to quiet a false positive. If protection metadata for fixed stubs/vias collides with its own real copper once legal net geometry is exported, change the DSN model and demonstrate the old physical clearances independently. Do not simply drop unrelated genuine keepouts.
5. Merge into the same unchanged pre-route KiCad copper, repour, and independently reload the serialized KiCad and Gerber geometry. From resulting **ground-net** In1 polygons (not total copper), verify `covered.covers(S)` so no new antipad, RF bleed or board-edge geometry has removed the reservation. Validate all claimed pad membership in actual positive-area ground copper components and exact plated connectivity through the board. This requires the final independent four-layer LVS and all original spacing, VIP, Gerber, manufacturing and mechanical gates, as before. The Shapely prepass alone cannot certify what the final router will drill. If proving `S` is retained geometrically is too strict in real designs, an equivalent certificate of physical anchor-to-anchor connectivity needs separate evidence and tests before it can replace that condition.
6. Conservative deterministic backoff: if the preliminary witness is invalid, use full physical net ownership/fixed copper without asserting the plane and route the real terminals. If post-route coverage fails, save the failed candidate input/output and route the same board deterministically from pristine physical copper with **no speculative plane in DSN**. Verify the backoff independently. Do not load a speculative SES and assume a new layout, count lost plane coverage as pass, parse an older run's output, or use copper from a rejected result. If backoff fails, report it. The uniform versioned criterion is geometric, not case-ID selection.

## Acceptance fixtures to require before production

- The seven engine scenarios above, plus a direct Shapely proof that the real KiCad candidate has one physical component only when all anchors contact the same real reserved plane.
- Arbitrary 1 µm quantization near split polygons plus a narrow window that opens a bridge. Require no omitted void or disconnected component, section with overlapping polygons, or extra plane copper beyond the approved envelope.
- An initially valid seed where a routed foreign via antipad completely severs the advertised reservation. The candidate must be rejected and the full audit must run after deterministic backoff. A via outside the reserved witness should pass if every other gate does.
- Same-text pin repeated by a real copper sub-pad, same net separate return domain, and distinct unrelated overlap. All coordinates transformed consistently. A wrong net label or Layer-only projected contact fails.
- Through, thermal and non-through padstack fixtures with locked existing plating; prove ordinary newly routed nonthermal Via-in-Pad remains prohibited.
- Check selected SES merge leaves exactly one of each original fixed wire/via and does not change its geometry. Number of freely routed targets and strict spacing/opens are comparable to the frozen stable default individually, no new waivers.

No project files were edited and no sealed PCB was accessed for this investigation. A production patch is premature until choosing a shared physical plane geometry API and selective guards for intentional thermal contacts. The load/run proof above is sufficient to justify a future separately frozen candidate, not a manufacturing pass.
